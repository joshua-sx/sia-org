# SIA — Smart Performance Management

SIA is a modern multi-tenant HR platform designed for performance appraisals, goal tracking, and organizational development.

## Features

- **Multi-tenant architecture** with secure tenant isolation via JWT custom claims
- **Role-based access control** (HR Admin, Manager, Employee)
- **Organizational structure management** with custom hierarchy levels
- **Performance appraisal workflows** (coming soon)
- **Goal tracking and OKRs** (coming soon)

## Tech Stack

- React + TypeScript
- Tailwind CSS
- shadcn/ui components
- Lovable Cloud backend

## Development

```bash
npm install
npm run dev
```
